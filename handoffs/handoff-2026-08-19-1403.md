## Decisions & conventions
- `pdf_design_spec.md` is now the **authoritative visual reference** — implement
  against its measured values, not `pdf_export_spec.md`'s older visual-estimate
  language (still useful for document-structure/product decisions, but corrected in
  §3/§4.2/§6 to defer to the design spec on visuals).
- Cover-only tutorial decorations (sparkle burst, pickaxe-bubble callout, wavy path
  texture) must **never** appear on real question or answer-key panels — this was an
  actual bug in the first renderer spike, now fixed and documented as a hard rule in
  both docs.
- Per-maze-type question rendering must go through a registry (`QUESTION_TYPES` /
  `PDF_QUESTION_PANELS`), never hardcoded PickAxe layout in the page-composition code
  — established this session specifically because more maze types are coming.
- All renderer-tech spikes are throwaway and clearly marked as such (comments in every
  file, README explains removal). Don't mistake any of `Web App/spikes/pdf-renderer/`
  or `Web App/frontend/src/spike/` for production code.
