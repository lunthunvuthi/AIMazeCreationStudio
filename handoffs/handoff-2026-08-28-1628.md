A refresh no longer discards an in-progress sheet.
- `storage/localStorageAdapter.ts` — **one slot**, holding a bare `LevelProgress`

### PR #10 — OPEN (`685427f`). Roadmap step 6.5: `sheetId` + `formatVersion: 3`

## Gotchas / watch-outs
- **The app needs THREE processes:** backend `:8000`, Vite, pdf-service `:8010`.
- **`localStorage` lags the store by up to 500 ms** (`WRITE_WINDOW_MS`). Reading it
  immediately after a store action returns the **previous** sheet. Cost one debugging
  round — a `question_id` from the old sheet 404'd against the new one.
- **`autosave_check.mjs` used to fail on its first run after any source edit.** Vite
  reloads the page itself after an edit, destroying the execution context under an
  in-flight `evaluate`. **Fixed** — all 11 call sites retry — and the fix was proven by
  touching a source file and running immediately, *not* by re-running until green.
- **Two harness bugs found this session that "passed for the wrong reason"** — the class to
  watch for:
  1. A selector matching **nothing**, so a bounds assertion passed vacuously on all four
     cases. Now throws unless exactly 2 header text nodes are found.
  2. Composing `getCTM()` onto `getBBox()` — folds in the viewBox scale **1.3334** and
     reported a **false overflow**. `getBBox` is already in user units.
  3. (Earlier, same family) a `try/finally` with no `catch` printing "10/10 passed" over a
     thrown locator error.
- **`getByRole('link', {name: 'Resume'})` is ambiguous** on the maze-type home — "Modify
  Maze / Resume from a saved level file" also matches. Use `exact: true`.
- **Randomize on the question-entry screen is a `<Link>` wrapping an `<h2>`**, not a
  button. Click the heading.
- **`npx tsc --noEmit` in `Web App/frontend` typechecks ZERO files.** Use `npm run build`.
- **pdf-service defaults to `FRONTEND_URL=http://localhost:5173`.** The driver's
  `--frontend` points **the driver only**.
- **A stale Vite from an older session holds `:5173`.** Left alone across four sessions
  now; everything this session used `:5174`.
- `scripts/run_backend.py` dies under `nohup … &` (watchdog, by design).
- `Playwright locator.count()` does not auto-wait.
- Preview's blob tab is a *download* in headless Chromium — never wait on download counts.
- One pre-existing lint warning: `spike/pdfMazeTypeRegistry.tsx:85`.
- Still **no frontend test runner**; all frontend guarantees are browser-driven.
- `development_plan.md` §4.3 was still presenting the `formatVersion: 1` snippet as
  current until #10 rewrote it. `frontend_reference.md` **is still stale in places #8/#10
