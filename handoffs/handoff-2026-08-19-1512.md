## Decisions & conventions
- **Real vector assets are authoritative** over any hand-drawn/estimated shape
  wherever they overlap — see `pdf_design_spec.md` §12's per-file "Superseded" notes.
- **The laurel-wreath/Bonus marker is manual now, not computed.** Any future work
  touching page numbering must read `PageRow.isBonus`, never re-derive it from star
  ratings.
- **Icon fill colors were normalized to the existing ink color (`#111111`)** in the
  frontend spike's `VectorAsset`-based icons for visual consistency, even though the
  source vectors use slightly different near-blacks (`#15120e`/`#231f20`/`#414042`).
  This was an implementation call made without a separate explicit confirmation from
  the user — flag it if it turns out to matter, it's a minor and easily-reversible
  choice.
- **Spikes stay spikes.** The frontend spike (`Web App/frontend/src/spike/`) and both
  renderer spikes under `Web App/spikes/pdf-renderer/` are still explicitly throwaway/
  comparison-only — don't mistake today's icon-swap work there for production code.
- **Scope cuts are deliberate, not oversights**: the dashboard redesign's
  drag-and-drop and Preview/Download were explicitly deferred by the user's own choice
  this session (asked directly via `AskUserQuestion`), not skipped by omission.

  swap — it still uses its own hand-drawn shapes. Don't assume it matches the frontend
