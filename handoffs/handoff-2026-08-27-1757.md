## Gotchas / watch-outs
- **`npx tsc --noEmit` in `Web App/frontend` typechecks ZERO files.** Use `npm run build`.
  Now in CLAUDE.md *and* the README.
- **The app needs THREE processes, not two.** `Web App/pdf-service` on `:8010` backs
  Preview / Download / Answer Key; without it all three fail with a 503. Now in the README.
- **pdf-service defaults to `FRONTEND_URL=http://localhost:5173`.** When Vite finds 5173
  held it silently moves to 5174 — the service then renders against whatever stale dev
  server is squatting on 5173. This bit during the session; pass `FRONTEND_URL` explicitly.
- **`scripts/run_backend.py` dies instantly under `nohup … &`.** Its terminal-death
  watchdog working exactly as designed — a backgrounded Bash call's shell exits, so it
  tears down (log says `stopping backend (parent shell exited)`). Symptom is a 502 through
  the Vite proxy a few seconds later. Use a genuinely persistent terminal/background task.
- **A stale Vite from an earlier session was holding 5173** (pid 53501 at the time). Left
  alone deliberately — not this session's process to kill.
- **Changing a slot's Difficulty renames its `question_id`** (`kinder-1star-1` →
  `kinder-2star-1`). Collision-safe (`setQuestionStar` uses an occurrence counter), but it
  invalidates any href/selector held across the change. It also discards the authored maze
  — **which is guarded**: `handleChangeStar` confirms first. This was reported mid-session
  as an unguarded bug and that was **wrong** — the store action was read without its
  caller. Nothing to fix.
- **A new level is seeded with 8 empty slots across 5 rows**, not an empty sheet. "Add
  question" only appears on rows holding one question; empty slots are ordinary cards.
- **Playwright against this dashboard**: after `waitForURL('**/dashboard')` the rows have
  not re-rendered yet — `locator.count()` returns 0. Use `waitFor({state:'visible'})`
  instead of counting. Cost two failed runs.
- No test runner in the frontend. Verification here was browser-driven; the scripts are in
  the session scratchpad and are **not preserved**.
- One pre-existing, unrelated lint warning in `spike/pdfMazeTypeRegistry.tsx:85`.
