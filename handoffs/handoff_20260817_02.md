## Decisions & Conventions
- The web app plan is intentionally maze-type-agnostic at the architecture level (registry
  pattern for maze types) even though PickAxe Maze is the only type today.
- The JSON save/load format IS the `LevelProgress` type — no separate "save file" schema;
  partial and complete progress use the same shape, differing only in per-question status.
- No new abstractions beyond what's speced — avoid scope creep into multi-maze-type work
  until a second type is actually requested.
